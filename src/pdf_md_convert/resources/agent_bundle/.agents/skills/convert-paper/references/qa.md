# Review and completion

Read automatic findings before editing. Missing in-PDF exhibits and incomplete page coverage require reconciliation. A context crop is not a reconstructed equation, and a caption is not a reconstructed table.

External appendix references may be legitimate source limitations, but confirm what the supplied files contain. Low-confidence regions are review queues. Pending work is not a source limitation.

Pages in `damaged_text_pages` have font glyphs the text layer cannot name; they appear as `�`. Transcribe those symbols from the rendered page or record them as unreadable. Never guess them from context.

Recheck each corrected region against its source image and inspect the surrounding paragraph/table boundary. Record correction provenance, task IDs, source hashes, pages and review notes. Mark drafts verified only after inspection. A comparison with manuscript.md may detect differences, but the derivative can contain AI enrichment or errors.

The final handover must distinguish execution results, automatic validation, sampled visual review and whole-document review. If unresolved hard findings remain, report an incomplete review rather than a final manuscript.
